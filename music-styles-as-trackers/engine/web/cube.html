Parameter groups

x: tracks · down: steps (time) · into the screen: every parameter shaping each step. A box's size and brightness is the value, 0 to 1 over the parameter's range. Amber boxes are locked on their step; pale ones are set by a track command; grey ones are unset, shown at the schema's default (unset values with no documented default are left out); white-tinted ones changed since the track's previous step. Drag to orbit, scroll to zoom, hover for values.
